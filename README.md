## 📌 Deskripsi Proyek
Website ini dibuat sebagai bagian dari tugas perkuliahan untuk mengimplementasikan *version control* menggunakan **Git dan GitHub**, meliputi:
- Pembuatan repository lokal dan remote.
- Pengelolaan commit perubahan file.
- Pembuatan branch fitur (`fitur-produk`).
- Penggabungan kode melalui *Pull Request* (PR) dan *Merge*.
